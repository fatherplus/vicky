# BOOK-STYLE：书页风格设计规范

> 这个仓库是一本书，不是一堆网页。
> 书的每一页风格统一，有封面、有目录、有页码。读者翻开任何一页，
> 都应该立刻认出"这是同一本书"。
>
> 本文件是**硬约束**（hard constraints），不是建议。
> 约束方式参考 [taste-skill](https://github.com/Leonxlnx/taste-skill)：
> 先做设计读取，再用绝对禁止清单 + 具体数值规则约束输出。

---

## 0. 设计读取（Design Read）

动手前先声明一句话设计读取（照抄即可，不要自由发挥）：

> "Reading this as: 技术研究文集 for 技术决策者与工程师, with a 学术专著 / 书卷气
> language, leaning toward 书页版式 + 宋体标题 + 大量留白 + 克制动效."

- **页面类型**：长文阅读（研究报告），不是落地页、不是仪表盘。
- **读者**：技术团队 / 领导，逐字阅读，需要可信、安静、不费力。
- **气质**：学术专著、古籍整理本——克制、规整、有书卷气，不要炫技。
- **核心隐喻**：书。报告 = 章节页，索引 = 封面 + 目录，顶部进度条 = 书签丝带。

---

## 1. 三个旋钮（为"书"固定，不要调）

| 旋钮 | 值 | 理由 |
|------|----|------|
| `DESIGN_VARIANCE` | **4** | 书是规整的，版式稳定可预期，不追求艺术化混乱 |
| `MOTION_INTENSITY` | **3** | 动效克制——存在但不打扰阅读 |
| `VISUAL_DENSITY` | **3** | 疏朗，大量留白，像排印讲究的书 |

---

## 2. 绝对禁止（Anti-Slop，违反即不合格）

- ❌ 居中的 hero 三件套（大标题 + 副标题 + CTA 居中堆叠）
- ❌ 3~4 个等大特性卡片排成一排
- ❌ 渐变填充的标题文字；靛蓝/紫/粉渐变
- ❌ 只用 Inter / Geist / Roboto / Arial 单一字体
- ❌ 全站玻璃拟态（glassmorphism）、到处都是 rounded-2xl、极光色块背景
- ❌ 奶油米色 + 赤陶色（terracotta）+ 衬线 的"AI 文艺"默认组合
- ❌ 近黑背景 + 单一霓虹/酸性亮色
- ❌ 密集报纸式多栏 + 满天飞的 hairline 细线
- ❌ 标题/正文里用 emoji（书不用 emoji；用文字、数字、符号）
- ❌ AI 文案腔："赋能 / 闭环 / 打通 / 一站式 / 全方位 / 引领"——写具体、朴素的话
- ❌ 占位假数据（"张三 / Acme / Lorem Ipsum"）——用真实内容

---

## 3. 字体架构（Typographic Architecture）

靠**极致的字号/字重对比**和**宋体标题**建立书卷气，绝不靠花哨装饰。

| 角色 | 字体 | 字重 | 备注 |
|------|------|------|------|
| 标题 / 章节（Display） | `'Noto Serif SC'`（思源宋体） | 600 / 900 | 书的骨架，必须用宋体 |
| 正文（Body） | `'Noto Sans SC'` | 400 / 500 / 700 | 屏幕阅读更清晰 |
| 代码 / 日期 / 元信息 | `'JetBrains Mono'` / `'SF Mono'` | 400 / 600 | 等宽，用于日期、页码、标签。等宽字体无 CJK 字形：`--mono` 栈尾必须挂 `'Noto Sans SC'` 兜底；眉标（`.section-label`/`.opener .kicker`）中文落宋体 600 |

**字号阶梯（强对比）**：
- 章标题（h1）：`clamp(36px, 5vw, 52px)`，行高 1.25，字重 900
- 节标题（h2）：`26px`，行高 1.35，字重 900（宋体）
- 小节（h3）：`19px`，字重 700（宋体）
- 正文：`16.5px`，行高 **1.9**（中文需要大行距），段间距 18px
- 元信息 / 页码：`12-13px`，等宽字体

**规则**：正文绝不用纯黑 `#000`，用墨色 `#23272E`；标题用宋体、正文用黑体，
形成"宋题黑身"的经典书籍搭配。

---

## 4. 配色（Color Palette）

颜色是稀缺资源。整本书 = 暖纸 + 墨字 + 一个主色 + 一枚朱砂印章。

| 用途 | 色值 | 说明 |
|------|------|------|
| 纸（背景） | `#FBFAF7` | 暖白，像书页，不是刺眼的纯白 |
| 墨（正文） | `#23272E` | 墨色，不用纯黑 |
| 次要文字 | `#6E7278` | 灰，用于元信息、页码 |
| 主色（accent） | `#0C4A6E` | 深靛蓝——章节号、链接、强调线（延续平台品牌） |
| 朱砂（seal） | `#A63A2E` | **只用于"印章"小元素**（书签丝带、藏书章），绝不铺开用 |
| 分隔线 | `rgba(0,0,0,0.08)` | 极淡的 hairline，一本书只用少量 |

**规则**：朱砂红是"印章"，一页最多出现 1~2 处小面积（如顶部书签、标题旁的章）。
主色是靛蓝，不是红。这样才是"学术书"，而不是"AI 文艺奶油风"。

---

## 5. 版式（Page Layout）—— 舒展的"书页"

每一页报告都是同一个"页面模板"，字大、区域大、阅读轻松：

- **统一内容栏**：版心 `max-width: 1100px`，章节内容统一收进 `940px` 居中栏。标题、散文、卡片、表格、图、步骤共享同一条左右边界，避免同一章节出现多套错位的排版网格。
  正文使用 `17.5px`、行高 `1.95`、中文两端对齐（`text-align:justify`）+ `orphans/widows:3`；阅读节奏由字号、行距和组件留白负责。
- **吸顶导航（两行）**：
  - 第一行：`← 返回目录` 按钮 + 《报告标题》 + 朱砂藏书章
  - 第二行：**章节 tab**（由 h2 自动生成，滚动定位 scrollspy，点击跳转）
- **书签丝带**：顶部 `3px` 朱砂红进度条，随滚动变长
- **章节扉页（深色）**：全宽深色背景 + 巨大宋体标题 + 副标题 + 元信息，
  右侧盖一枚朱砂"藏书章"（微旋转），背景一个超大淡水印"藏"——本书的签名细节
- **内容节**：全宽、`padding: 92px 0`，**交替底色**（纸白 / 暖米）形成节奏，
  每节内部用 `.wrap`（1100px）约束
- **页脚（跋）**：深色，本书名 + 日期作者 + 返回目录链接

## 6. 组件规范（Component Specs）

**铁律：文档写的 = 模板里有的。** 指南出现的每个类名，`templates/book/template.html` 必须真实定义；能用原生标签（`blockquote`/`pre`）就不造类名。10 个标准组件：

| 组件 | 类名 | 规则 |
|------|------|------|
| 卡片 | `.card` | 白底，`border: 1px solid var(--hair)`，圆角 10px（不要 18px+），阴影极淡 |
| 数据表 | `.data-table` | 三线表风格；**只摆数据、不给结论** |
| 对比表 | `.cmp-table` + `.cmp-verdict` | 有“选谁”就用它；必须标推荐列、统一取值符号、表尾必填结论区 |
| 图 | `.figure` + `.fig-cap` + `.fig-note` | 一切图表/趋势/截图/示意图的固定装裱；框固定、画自由；必有图题（图 N · 标题）+ 图注（所以呢） |
| 引用 | `blockquote`（原生） | 左侧 3px 靖蓝竖线 + 暖白底，宋体；不用引号 emoji |
| 强调框 | `.callout.note` / `.callout.warn` | 淡底 + 左侧竖线；注意=靖蓝，警告=淡朱砂，不用大红大绿 |
| 代码块 | `pre` / `code` | 深墨底 `#1D1F24`，等宽，圆角 10px，不用彩色渐变边框 |
| 标签 | `.tag` | 小号等宽，淡底，圆角 4-5px，**不用**胶囊大圆角 |
| 步骤 | `.steps` / `.step` | 编号方块 + 标题 + 描述，编号用宋体数字 |

列表：正文用实心小圆点（`ul li::marker` 靖蓝色）。

---

## 7. 目录页（Index / TOC）—— 封面 + 目录

`public/index.html` 是这本书的**封面 + 目录**，必须做成书的样子：

- **封面区**：
  - 顶部书眉（书名 + "目录"）
  - 巨大的宋体书名《AI 研究报告集》+ 一行副标题（"技术研究与方案归档"）
  - 一枚朱砂藏书章（"Vicky" 或 "藏"），微旋转，作为签名
  - 卷信息（如"第一卷 · 2026"）
- **目录区**：
  - "目录" 二字（宋体，带一条靛蓝短线）
  - 每条目录项：`日期（等宽） + 标题（宋体） + 点状引导线（dot leader ……） + 序号`
  - 目录项 hover：标题变靛蓝、整行右移 4px、引导线变色
  - 按月分"辑"（如"2026 年 7 月"），辑标题小字等宽
- **不要**把目录做成卡片网格——目录就是目录，一行一条，带点状引导线。

---

## 8. 动效（Motion）—— 存在但不打扰

- **滚动进入**：元素淡入 + 上移 `translateY(14px)`，`600ms`，
  `cubic-bezier(0.16, 1, 0.3, 1)`，用 `IntersectionObserver`（禁止 scroll 监听硬算）
- **目录/卡片 hover**：`200ms` 的颜色/位移过渡，不要弹跳、不要 3D
- **书签进度条**：随滚动变宽（这是唯一"持续"的动效，且极安静）
- **跨页过渡**（目录 ⇄ 文章）：浏览器原生 View Transitions API（`@view-transition{navigation:auto}`），
  `450ms` 淡入淡出 + 横移 `20px`，方向即隐喻——进文章 = 从右往左翻，回目录 = 从左往右翻。
  零 JS；不支持的浏览器自动降级为直接跳转，不得为此写 polyfill
- **只动 `transform` 和 `opacity`**，不动 layout 属性
- **尊重 `prefers-reduced-motion`**：用户关闭动效时，全部静态

---

## 9. 执行协议（Execution Protocol）

写 / 改任何报告页面时，按顺序执行：

1. 声明设计读取（第 0 节那句话）。
2. 从 `templates/book/template.html` 复制——**模板是唯一 CSS 来源**，禁止从旧报告抄 CSS。
3. 先搭页面骨架：书眉 + 章节开头 + 720px 正文栏 + 页脚 + 书签进度条。
4. 套字体阶梯与配色（第 3、4 节），宋体标题、墨色正文。
5. 内容按 `skill/SKILL.md` 的汇报方法论组织（先讲为什么，再讲是什么）。
6. 加克制动效（第 8 节）与组件样式（第 6 节）。
7. 对照第 2 节"绝对禁止"逐条自查——违反任何一条即返工。
8. 更新 `public/index.html` 目录（按第 7 节的目录格式）。
